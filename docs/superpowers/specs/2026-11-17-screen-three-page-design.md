## 1. 背景与目标

流量压力检测集成装置需要一块大彩触摸屏作为人机界面：

1. **第 1 页（标题页）**：显示仪器名"流量压力集成检测仪器"，按「进入」进第 2 页
2. **第 2 页（实时数据页）**：顶部标题；双栏显示 流量1~3（左，青色）、压力1~3（右，橙色），每路一个**统一 200×60** 数值显示框；带单位标注（m³/h、MPa，占位，传感器到货后可改）；右上「定时设置」进第 3 页，左上「返回」回第 1 页
3. **第 3 页（定时采集页）**：6 行 = 名称 + 开始[时][分] + 停止[时][分] + 实时数值框；底部「采集」「停止」按键；**只有定时模式**（无手动立即启停）：
   - 「采集」= 启用全部 6 路时刻表；启用瞬间已处于窗口内的通道立即开始
   - 「停止」= 取消全部时刻表并立即停止所有采集

## 2. 系统架构（与既有固件同构，fattyWater3.0 已验证过的模式）

```
大彩屏 DC80480DN070 (7寸 800×480)          STC32G144K246 (modbus6_rtos)
┌─────────────────────────┐   Modbus-RTU   ┌──────────────────────┐
│ VisualTFT 工程           │  9600 8N1 485  │ Modbus 从站 地址=1    │
│  · Modbus 主机模式       │◄────UART8────► │ (screen.c, DE=P10.7) │
│  · script.xml 变量表     │                │ 寄存器表见 §4         │
│  · 控件 bind_variant 绑定│                │ TaskScreen/TaskSensor │
└─────────────────────────┘                 └──────────────────────┘
```

- 屏 = **Modbus 主机**，轮询从机保持寄存器；轮询周期 200ms、开启"优化读取"（只读当前画面相关变量，标题页时不发数据轮询帧）
- 固件 = 从站，已有 `screen.c`（03H 读 / 06H、10H 写）完整实现，本设计只**扩展寄存器表**
- 时间来源：屏把自己的 RTC 周期写到从机（大彩"写入时间"逻辑），MCU 存下用于时刻比较；屏不在线则时间冻结（设备以屏为唯一交互源，可接受）

### 3.3 script.xml 要点

- 根节点参数（参照 fattyWater 格式）：`protocol="1"`（Modbus 主机）`slave="1"` `cycle_time="200"` `pool_delay_time="10"` `response_timeout="100"` `mulitple_read="16"` `screen_optimize="1"`
- 变量表：6 个浮点读变量（§4 地址）、24 个 U16 写变量（时刻）、1 个 U16 写变量（0x0018 使能）、1 个 U16 读变量（0x001A 状态位图，预留）
- 浮点"字节顺序"属性必须与固件大端字序匹配 —— 枚举值见 §7 风险 R1
- "写入时间"逻辑：寄存器起始地址 0x0040（十进制 64），周期 1s

## 4. 寄存器映射（定稿，固件 config_app.h 注释同步更新）

### 读（屏 ← MCU，03H）
| 地址 | 内容 | 类型 |
|---|---|---|
| 0x0000~0x000B | 流量1~3 瞬时 / 压力1~3（float 大端字序，各占 2 寄存器） | FLOAT |
| 0x000C | 在线位图 bit0~5 | U16 |
| 0x0010~0x0015 | 流量1~3 累计（预留，本期页面不显示） | FLOAT |
| 0x0016/0x0017 | 流量/压力总线采集运行中（预留回读） | U16 |
| **0x001A** | **采集状态位图 bit0~5（各路当前是否在采集窗口内）** | U16 |

### 写（屏 → MCU，06H/10H）
| 地址 | 内容 | 语义 |
|---|---|---|
| **0x0018** | **定时采集总开关（重定义，旧"流量/压力立即启停"废弃）** | 1=启用全部时刻表；0=取消并立即停止全部采集 |
| **0x0020~0x0037** | 6 路×[开始时,开始分,停止时,停止分]，每路 4 个 U16：通道 i 的 4 个寄存器 = 0x0020+4*i | 时 0~23、分 0~59；开始==停止 视为该路窗口无效 |
| **0x0040~0x0046** | 当前时间：年,月,日,星期,时,分,秒（各 1 个 U16，屏周期写入） | 屏"写入时间"功能写入 |

### 窗口判定（固件实现规则）
- `g_run[i] = armed && time_valid && in_window(i)`，10ms 节拍在 TaskSensor 上下文评估（不在 ISR）
- `in_window`：`start ≤ now < stop`（按 分=hour*60+minute 比较）；`start > stop` 视为跨午夜窗口（`now ≥ start || now < stop`）；`start == stop` 窗口无效
- `time_valid`：收到过至少一次时间写入后才置位；未同步前所有通道不采集

## 6. 验证与验收

### 构建验证
- 固件：build-keil 全量重建，"0 Error(s), 0 Warning(s)"
- 屏端：VisualTFT 打开工程 → 编译通过（需用户点一次 GUI；生成物在 output/）

### 联调验证（消除"单侧假设"）
1. **float 字节序**：MCU 侧先让 0x0000 返回固定值 12.345f，屏模拟器（TFTSimulator.exe）或实屏显示 12.345 即字节序正确；显示异常则改屏端 byte_order 枚举重试（共 4 种组合，一次联调可穷尽）
2. **轮询行为**：串口抓屏发来的 03H 请求帧，核对地址/数量/周期与 §4 一致
3. **定时链路**：屏设窗口 → 写入时间到达 → 串口抓 UART5/6 出现该通道请求帧；停止后消失
4. **输入链路**：屏改时刻值 → 抓 06H/10H 写帧 → 固件回读 `g_sched` 确认

### 验收标准
- 第 1 页标题显示、进入/返回导航正常
- 第 2 页 6 路实时值刷新（与串口抓包值一致）、单位标注显示
- 第 3 页 24 个输入框可编辑并写入固件；采集/停止按 §4 语义工作；窗口外通道无轮询帧
